# Tourism Service API

## Тема проекта
Сервис бронирования туристических туров с возможностью поиска, избранного, отзывов и рекомендаций.

## Основные сущности
- **Tour** — тур (название, описание, цена, даты, гид, направления)
- **Guide** — гид
- **Destination** — направление (город/страна)
- **Booking** — бронирование тура клиентом
- **Review** — отзыв на тур
- **Wishlist** — избранные туры клиента

## Возможности сервиса (бизнес-операции)
1. Отмена бронирования с правилами возврата денег (100%/70%/0% в зависимости от сроков)
2. Добавление/удаление туров в избранное (Wishlist)
3. Поиск туров по ключевым словам
4. Получение популярных туров и направлений (по количеству бронирований)
5. Рекомендации похожих туров (по направлениям, гиду, цене, рейтингу)

## Как запустить
1. Установите PostgreSQL
2. Создайте БД `tourism_db`
3. Настройте `.env` с DB_USERNAME и DB_PASSWORD
4. Запустите приложение — таблицы создадутся автоматически
5. Используйте Postman-коллекцию для тестирования

## Endpoints
- `/api/tours` — CRUD туров + поиск, популярные, рекомендации
- `/api/bookings` — создание и отмена брони
- `/api/wishlist` — избранное
- `/api/reviews` — отзывы
- `/api/guides`, `/api/destinations` — справочники
